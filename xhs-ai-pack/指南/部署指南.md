# 部署指南 — 3步搭好 AI 选品推送

> 前置要求：一台 Mac 电脑，已安装 Node.js

---

## 第1步：安装工具（约10分钟）

打开终端，依次执行：

### 1.1 安装 Playwright 浏览器

```bash
npx playwright install chromium
```

等待下载完成，看到 "Chromium downloaded" 即可。

### 1.2 安装 Python 图片库

```bash
pip3 install Pillow
```

验证安装成功：

```bash
python3 -c "from PIL import Image; print('OK')"
```

输出 `OK` 就对了。

### 1.3 确认 mmx CLI 可用

```bash
mmx image generate --help
```

如果提示命令不存在，需要先安装 mmx（访问 mmx 官网获取安装包）。

---

## 第2步：配置变量（约5分钟）

打开 `配置/变量清单.md`，按说明填写：

- **必填**：飞书 Webhook URL（其他都有默认值）
- **选填**：自建图床地址（不填用默认公共图床）

### 获取飞书 Webhook

1. 打开飞书 → 进入要推送的群聊
2. 点右上角「设置」→「群机器人」→「添加机器人」
3. 选「自定义机器人」→ 复制 Webhook 地址
4. 粘贴到变量清单对应位置

---

## 第3步：运行工作流（约5分钟）

### 3.1 首次运行

在终端执行：

```bash
cd /你的工作区目录/
```

然后在 WorkBuddy 中发送：**好物推荐**

工作流会自动执行以下8步：
1. 搜索今日热门商品
2. 生成5个商品详情
3. AI生成商品配图
4. 生成精美HTML详情页
5. 自动截图
6. 压缩图片
7. 上传图床
8. 推送到飞书群

### 3.2 检查结果

- 飞书群里应该收到一条消息，含5款商品图文链接
- 本地 `output/今日日期/` 目录下有所有产物文件

### 3.3 设置每日自动运行

在 WorkBuddy 中创建定时任务，每天自动执行。
