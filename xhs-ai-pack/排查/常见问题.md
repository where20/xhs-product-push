# 常见问题排查

> 卡住了？按编号对照解决

---

## 1. `mmx: command not found`

**原因**：mmx CLI 未安装

**解决**：
- 访问 mmx 官网下载安装包
- 安装后重启终端
- 验证：`mmx image generate --help`

---

## 2. `Executable doesn't exist`（Playwright 报错）

**原因**：Chromium 浏览器未安装

**解决**：
```bash
npx playwright install chromium
```
等待下载完成，重新运行工作流。

---

## 3. `ModuleNotFoundError: No module named 'PIL'`

**原因**：Python Pillow 库未安装

**解决**：
```bash
pip3 install Pillow
```
验证：`python3 -c "from PIL import Image; print('OK')"`

---

## 4. 飞书群没收到消息

**可能原因**：
1. Webhook URL 填错了 → 重新复制粘贴
2. 飞书机器人被移除了 → 群设置里确认机器人还在
3. 网络问题 → 终端执行 `curl -I https://open.feishu.cn` 看能否连通

**排查**：终端手动测试 Webhook：
```bash
curl -s -X POST "你的WEBHOOK_URL" \
  -H "Content-Type: application/json" \
  -d '{"msg_type":"text","content":{"text":"测试消息"}}'
```
群里收到"测试消息"说明 Webhook 正常。

## 5. 图片上传失败 / 图床报错

**可能原因**：
1. 默认图床暂时不可用 → 稍后重试
2. 图片文件太大（>10MB）→ 检查 `product_card_full.jpg` 大小
3. 自建图床参数名不对 → 确认上传参数名是 `image` 不是 `source`

**解决**：
```bash
# 检查图片大小
ls -lh output/*/product_card_full.jpg

# 手动测试上传
curl -F "image=@output/今日日期/product_card_full.jpg" \
  https://cloudimgs.231203.xyz/api/upload
```

---

## 6. 图片变形 / 被裁切

**原因**：HTML 中图片容器设了固定高度

**解决**：检查 `product_card.html` 中 CSS：
```css
/* 错误写法 */
.product-image-wrap img { height: 300px; }

/* 正确写法 */
.product-image-wrap img { width: 100%; height: auto; }
```
