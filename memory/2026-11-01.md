## 🐛 踩坑与新发现

1. **⭐ jd 榜单页「打印时截断主图 URL」——不是图片坏，是显示截断**
   → `jd_fetch.py` 控制台输出用的是 `主图={p['image'][:96]}`，**URL 被截到 96 字符**，
   手工拼 `/n1/s450x450_jfs/` 下载会拿到 552 字节的 400/405 错误页。
   → **正确做法：直接用 `jd_fetch.py --imgs --outdir <dir>`，它按 SKU 命名落盘真实 450×450 图**，
   文件名就是 sku（如 `1750036.jpg` = 珂润、`906180.jpg` = 蜂花）。
2. **⭐⭐ 主图里印着价格 —— 比任何比价站都准**
   → 骆驼雪地靴主图右下角印「¥169 双11 官方无门槛单直降」，蜂花主图印「单瓶到手价 ¥19.9 11.11 抢先购」。
   → **价格与 SKU 严格同源、零串货**，今天 2 个主推品靠它定死了价格。
   → 以后选品应优先：先 jd 榜单页拿 name/sku/评论数 → 下载主图 → **肉眼读主图上的价格** → 再用 maigoo/好价站交叉验证。
3. **`key_*.html` 榜单页内容会轮换**（同 URL 两次抓返回不同品类，10-29 已知，今天再次验证）
   → `key_1316fc0138e14b4e8448`（面霜榜）抓出来是薇诺娜/珀莱雅；
   `key_1316f05977f33e90c2c9`（神经酰胺榜）才出珂润。
   → **同一个品类要多试 2~3 个榜单 URL，再逐条 read 真实商品名。**
4. **`maigoo.com/product/specs_{id}.html` 的价格与商品名是分开两个正则块的**
   → 直接正则抓「名称 + 价格」会错位（价格段落后紧跟的是**上一条**商品的网店名）。
   → 正确姿势：`参考价格[:：]\s*￥\s*([\d.]+)` 往前回看 90 字符再切名称。
5. **`paihangbangtuijian.com` 的价格是 HTML 实体 `&yen;239` 不是 `¥239`**
   → 正则写 `¥` 匹配不到，得先 `html.unescape()` 或直接匹配 `&yen;`。
6. **`zhuomiwang.com` curl 返回 HTTP/2 stream error（code 92）** → 换用 smzdm 实测帖 + maigoo 代替。
7. **`s450x450` 直连图片要带 `Referer: https://www.jd.com/`**，否则 405。
8. **探拓不在任何 jd 榜单页的 TOP10 里**（jd 榜单头部全是骆驼/伯希和/北面/凯乐石），
   → 最终用 `m.smzdm.com/p/128726288/`（202，通过闸门）+ `post.m.smzdm.com` 实测帖 + `wiki.smzdm.com` 规格页三重取证。
   → **备选法：把"品类里价格带最低/性价比最高"的品牌当主推，比选大牌更能打。**
