## 🐛 Bug 发现与修复

### Bug 1: mmx CLI 网络失败 (修复)
- **现象**: `mmx image generate` 报 `code 6, Network request failed`
- **根因**: mmx 配置 proxy `http://127.0.0.1:7897`,但该端口实际**没有进程在监听**(lsof -iTCP:7897 查无)
- **修复**: 写 `scripts/gen_images_20260909.mjs` 直接调用 minimaxi API (`https://api.minimaxi.com/v1/image_generation`) 绕开 mmx CLI 包装
- **下次改进**: 启动前 `lsof -iTCP:7897` 检测,proxy 不在则用直连方案

### Bug 2: HTTPS_PROXY env 阻断 cloudimgs 上传 (修复)
- **现象**: `python3 scripts/upload_cloudimgs.py` 报 `Connection refused`(cloudimgs 41.157.193.147:443)
- **根因**: 继承 shell 的 `HTTPS_PROXY=http://127.0.0.1:7897`,走不通
- **修复**: 跑上传时 `env -u HTTPS_PROXY -u HTTP_PROXY` 清掉代理环境变量
- **下次改进**: upload_cloudimgs.py 内部 `os.environ.pop('HTTPS_PROXY', None)` 兜底

### Bug 3: db_export.py 创建 v/{old_version}/ 目录残留
- **现象**: db_export.py 内部生成 v/{ts1}/ (我看到 1788908948),但页面需要 v/{current_version}/
- **修复**: 在 step 12 手动 mkdir 当前 VERSION 目录 + cp 文件(与 v/{old_version}/ 冗余但避免 404)
- **下次改进**: db_export.py 接受一个 `--version` 参数,直接用最新 VERSION 覆盖
