**最终解法（比 prompt.md 的 prompt 改写更有效，值得固化）**:
既然 prompt 层面压不住 AI 造字，就**直接改像素**——把乱码所在的那一条带（y 696~724, x 386~448）
用**上下干净参考行做纵向线性插值**填平，再对过渡带做 2.2px 高斯模糊：
```python
for x in range(386, 448):
    v_top, v_bot = px[x, 691], px[x, 730]      # 上下干净行
    for y in range(696, 725):                   # 乱码带
        t = (y - 691) / (730 - 691)
        px[x, y] = 插值(v_top, v_bot, t)
```
验证：修复区 **min 亮度 169 → 241，dark(<200) 像素 35 → 0**，放大 5× 复查已完全干净。
⚠️ **踩坑：先试过"克隆机身左侧素面区域"失败了**——用 ASCII 亮度图才看清，
该机身在 x<380 全部是**左侧阴影渐变**（`++++***###%%%%%`），根本不存在可克隆的平白区。
