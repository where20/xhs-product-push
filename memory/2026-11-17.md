### ⭐ 解法一：`mmx --subject-ref`（本日最有用的一条）

**手柄 / PS5 这类"高语义 logo 物体"，纯文生图 100% 会编造 logo 与字母键**：
本日连试 **7 次**纯文生图全部失败 —— Xbox 圆标、ABXY 字母键、假电源图标、假五点菜单、
假"≡"横线，甚至"背面朝上"也被 AI 画成正面。**堆禁止词无效**，因为 AI 认为手柄"就该有 logo"。

**改成带真实主图做主体参考，一次就干净**：
```bash
# 1) 从真实京东主图裁出纯产品区（避开价格条 / 文字横幅 / 品牌字）
python3 -c "
from PIL import Image
im=Image.open('主图450x450.jpg').convert('RGB')
im.crop((148,58,448,330)).resize((600,544),Image.LANCZOS).save('/tmp/ref_pad.png')"
# 2) 带参考图生成
mmx image generate --prompt "Professional studio product photography of a white wireless
game controller with metallic blue ring accents around both analog sticks, resting on a
light grey seamless studio surface, soft diffused lighting, clean minimalist e-commerce
catalog style, ultra sharp detail, the product is completely faithful to the reference
image, no text, no watermark, 1:1 square composition" --aspect-ratio 1:1 \
  --subject-ref "type=character,image=/tmp/ref_pad.png" --out out.jpg --quiet
```
产出：手柄**顶面视角**（两只蓝环摇杆 + 肩部扳机），零按键零字母，形态与真实飞智冰原狼4 一致。
⚠️ `--subject-ref` 在 `mmx image generate --help` 里没写明 `type=` 只支持 character，但物体照样生效。

### ⭐ 解法二：小面积假字不用重出，用定向插值填充

对"干净平面上的小块假字"，重新出图成本高且可能引入新问题，**直接修**更可控：
- **水平插值**（适合左右方向有渐变的面，如音箱端盖）：取 bbox 左右各外扩 5px 的边界列，
  逐行线性插值填充 bbox，再与原图做高斯羽化混合
- **垂直插值**（适合上下渐变的曲面，如饮水机机身）：取 bbox 上下边界行，逐列线性插值
- **IDW 反距离加权扩散**：取 bbox 外 6px 环带像素，按 1/d² 加权填充整块，
  天然保留曲面明暗，适合圆形凸起按钮

⚠️ **不要用整块 clone patch**：克隆源区域会连带把邻近的**灯环亮弧 / 背景色**一起搬过来，
结果是一个明显的方形色块，比原来的假字更丑（本日踩过，音箱图第一版就是这样废掉的）。

### ⚠️ 本日新发现：卡片价格条会与大号编号重叠
价格串写长（如 `¥199(京东活动到手价·什么值得买日常常卖同价)`）后，右对齐的价格条会**压到
左上角 140px 大号编号 "05" 上**（¥ 符号与 5 重叠）。
- 约束：价格串总宽 ≤ ~800px（中文 ≤ 12 字 + 数字），即 `font_price=40px` 下大致上限
- **解法**：`price` 字段只写最短限定词（`¥219(到手价·三源互证)` / `¥299(活动到手价)`），
  完整价格来源放 `price_note`（卡片底部已经完整渲染），两者信息不丢
