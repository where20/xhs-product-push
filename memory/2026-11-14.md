本次实测出一条**可程序化、可批量**的新链路:

```bash
# 1) wiki 首页(630KB)能列出全部分类页, slug 是中文拼音
curl --noproxy '*' -sL -A "$UA" https://wiki.smzdm.com/ \
  | grep -oE 'href="https://wiki\.smzdm\.com/[A-Za-z0-9]+/"[^>]*>[^<]{1,40}'

# 2) 分类页形如 https://wiki.smzdm.com/{拼音slug}/ , feed 流每条含 商品名 + "XXX元起" + 商品页链接
#    翻页用 /p2/ /p3/ ...
# 本次验证可用的 slug:
#   chuangshangjiafang (床上家纺) / jiekouzhuanhuanqi (接口转换器)
#   tixuchumao (剃须除毛)     / xichenqi (吸尘器) / zhazhiji (榨汁机)

# 3) 条目结构: <li class="feed-row"> … 'article_title': '商品名' … 233.39元起 … <a href="https://wiki.smzdm.com/p/{id}/">
```

- ✅ 全程 HTTP 200,不限速,一条 curl 就能拿到整页 35 条「商品名 + 价格 + 商品页链接」。

  正则 `https://wiki\.smzdm\.com/p/[A-Za-z0-9]+/?` 抓,别写纯数字。
- ✅ 本次靠这条链路补齐了全部缺价竞品(飞科 FS903 ¥113、贝尔金 6 合一 ¥335.35、

## ⚠️ 踩坑与经验(给明天/下次)

1. **smzdm 价格源有三条独立链路,优先级要分清**:
   - `wiki.smzdm.com/{拼音slug}/` ← **最优先**(可程序化发现 + 批量 + 带商品页链接 + 不限速)
   - `www.smzdm.com/ju/{slug}/` ← 次优(slug 只能靠搜,容易找不着)
   - `m.smzdm.com/p/{id}/` ← 兜底(id 未知时没法用)
   - `m.smzdm.com/ju/...` 和 `search.smzdm.com` ← **都是 JS 挑战壳,别试**
2. **wiki 商品页 id 是字母数字混合**(`95wn78x`),正则要用 `[A-Za-z0-9]+`。
3. **京东主图 450×450 直连可用**,路径段 `/n7/s80x80_jfs/` → `/n1/s450x450_jfs/`;
   主图印价 = 与 SKU 同源的真实到手价,是比任何第三方都硬的价源。
4. **出图 prompt 必须有"形态锚点实体"**:果汁 / 滚刷头 / 刀网 / 网口。
   只写材质和颜色,AI 会给你一个"同色但不是那个东西"的物件。
5. **出图 prompt 的"禁止词"对带面板的家电 0 效果**,唯一有效的是**把带标签的部位移出画面**。
6. **候选图别覆盖原图**,`cp` + `mavis-trash` 回收;`mv -f` / `rm -f` 会被权限门拦
   (相对路径会被解析到 workspace 根目录),用 python `shutil.copyfile` 最稳。
7. **WebSearch(search_type=shopping) 输出会爆到 78KB+**,别通读,定向 grep。
8. **榜单页会轮换内容**:`key_15248f12b2519112d1cff` 搜"天然乳胶记忆枕"但实际页标题是"天然乳胶记忆枕排行榜"
   (内容对得上),而 `key_152483f2be7f67092cc56` 才是"记忆枕低价榜" —— **标题必须逐条 read 真实商品名**。
