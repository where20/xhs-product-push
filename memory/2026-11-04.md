## 🐛 踩坑与新发现

1. **三个比价站今天彻底挂了 —— `maigoo.com` / `m.maigoo.com`(502)、`maicul.cn`(000)、`taouq.com`(403)**（重试 3 次均失败）。
   → 它们的"参考价格"**只能写进 `price_note`/desc 做文字参考，绝不能进 `links` 或 `vs.json.sources`**（编造的链接 = 假带货链路）。
   → MISSION UV 的原始价源原本全在这三个站上，**必须换成可达且 SKU 精确匹配的 `smzdm ju/s346vvy`** 才能作主价。
2. **百度购物品牌榜是"京东榜单页"的直接替代品** —— `shopping.baidu.com/rank/brand?allowVoteInNewPageC=0&secondTagID=1&srcid=5881&srcidFrom=5881&tagID=424382986&word={关键词}`
   页面直接给「商品名 + 单价 + 销量」三元组（俞兆林 YG307 ¥23.88 销量92 / ¥22.69 销量94）。
   **京东榜单页价格恒空（JS 渲染），百度购物这条是本期新发现的可用价源**。
   ⚠️ URL 参数要带全（`secondTagID/srcid/tagID`），少参数返回的是空壳页（20KB 但无商品行）。
3. **`smzdm ju` 榜页会轮换商品、且价格会变** —— 大江 Ag 50x110 昨天记录 ¥77.9，今天同 SKU 是 **¥47.18**。
   → **价格必须当天现抓，不能沿用昨天日志里的数字**；写日志也要写当天实测值。
4. **「挂牌参考价」≠「活动实付价」，同一 SKU 能差 3 倍** —— 佩尔森 5L：搜狐 + 百度Feed 榜单给「京东参考价 ¥185」，smzdm 爆料页给活动价 ¥60.9 + 立减15% → 实付 **¥51.7**。
   → 两个数都是真的，**必须并列写进 `price_note` 并说明口径**，不能只挑一个、也不能把 ¥185 当实付价推给用户。
5. **`pinpai10.net/bang/*.html` 静态 HTML 里没有价格行**（JS 渲染），价格只存在于 web_search 快照里。
   → 昨天日志里"牌子网能取到券后价"的印象**再次证伪**；地垫组改用 `ju/spnv191` + `smzdm/p/116220043` 为主源，牌子网只作旁证。
6. **`m.smzdm.com/p/{id}` 返回 HTTP 202 而不是 200** —— `verify_links.py` 的通过判据是 **200 或 202**，202 同样算通过，不用改脚本。
7. **焱魔方电暖桌直接出局** —— 京东主图印 **¥1657**，远超 ¥500 上限。选型阶段就该先读主图价再定品，别等选完再砍。
8. 🔴 **出图 AI 给针织帽加标牌是"强先验"，光靠 prompt 写 `no label` 治不住**。
   - 试了 **3 版不同 prompt + 7 张候选**（含"卷起来只露帽冠"、"平铺俯拍"、"帽檐藏起来"），**每一张都带标牌**；
   - 标牌样式还各不相同：横向织唛带草写、白色方标带盾形徽章、带 "MO" 字样的小方标。
   - **最终解法**：改描述主体（"simple rounded crown + NO turned-up cuff band"）+ **`--n 3` 批量出候选再挑**，3 张里 1 张干净，直接采纳。
   - → **方法论升级**：出图别只盯 `no text`，**要换主体/构图去绕开 AI 一定会加标签的那类位置**（品牌标签通常在翻折边、袖口、标签贴、鞋面）；
   - → **`--n N` 批量生成 + 挑选** 比反复覆盖同一文件名更稳，**且每次覆盖前先备份**（本次备到 `/tmp/xhs_rejected_1104/`，未污染 `images/`）。
9. 🔴 **比"带标牌"更隐蔽的问题是"形态不对"** —— 荣事达欧式快热炉首轮出成**竖直塔式**（像油汀/塔式暖风机），颜色对、品类对，但和真实"宽扁横置的欧式快热炉"完全两回事；而且塔式造型历史 10-09 才用过（艾美特油汀），观感像重复品类。
   → 修法：prompt 里写死比例与姿态 —— **"low and wide / long slim horizontal rectangular unit about three times wider than it is tall / flat top grille / small feet / three-quarter front view"**，一次命中。
   → **肉眼核对不能只查"有没有字"，还要查"形态对不对"**。
10. **`item.jd.com` / `search.jd.com` / `api.m.jd.com` / `p.3.cn` / `smzdm.com/sou/` 依旧不可用** —— 继续用 `www.jd.com/phb/*.html` 做 `links.primary`（今天 5 个主推全部如此）。
11. **克隆修补标牌失败**（读坐标读偏 + 源区落在帽檐边缘的暗部，接缝明显）→ 放弃修图路线，**改用"批量生成挑干净的那张"**，更可控。
