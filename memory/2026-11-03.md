## 🐛 踩坑与新发现

1. **`pinpai10.net/bang/{品类}.html` 是「品牌榜」不是「商品榜」** —— 页面上只有品牌介绍 + 品牌下的精选商品轮播（威恒那次轮出来的是电机/钓鱼竿），**没有「销量 N 券后:¥X」这种行**。
   → 昨日日志里"pinpai10 能取到券后价"的印象**不成立**，价格要找 `ju/` 榜或 `wiki.smzdm.com` 百科页。
2. **`wiki.smzdm.com/p/{id}` 是汤婆子这类"有规格"商品的最优价源** —— 页面明文「XX 元起 / 京东 最低 ¥XX」，且**规格（18CM / 直径20cm / 200mm）逐字对应**，比 `ju/` 榜（只给标题不给规格）更适合绑 SKU。
3. **`smzdm ju` 页会轮换商品** —— 同一分类页两次抓内容不同（`ju/sqxr4yw` 第一遍有蓓安适、第二遍就没了），**不能只抓一次就下结论**，标题对不上时换页重抓。
4. **smzdm `ju` 页正则必须整段一起抽** —— 价格排在商品名前面；且**同一商品会连出多条不同价**（品喻 8 条、京惠思创 9 条），靠"标题逐字相同 + 平台 + 销量"三要素才能定位到那一条。
5. **`smzdm.com/p/{id}` 单品页可能退化成 JS 壳** —— `p/439703` 只有 1680 字节，`"price"` / `"name"` 全抓不到；`ju/` 页里能挖到 p-id，但 p-id 本身未必可用。**别在 p/ 页上死磕**。
6. **京东主图是"SKU 严格同源"的最强价格源** —— 本次金号擦手巾主图直接印「预计到手价 ¥31.20」，比任何榜页都准。**每个主推品都该下载 s450x450 原图读价**。
7. **SKU 级价格不一定绑得住** —— 品喻在榜页只有标题级价格（8 档），**没有** SKU 级映射。
   → 做法：取榜内套装价作主价，`price_note` 写明全部档位 + "下单前请按容量核对"，**不硬编一个容量**。
8. **出图 AI 会自己造品牌字** —— 首轮 product_5 的包装袋印着 "Travel VORERS" 乱码、护照上也有鬼画符；product_2 的洗衣机面板上出现 "COALEAING"。
   → prompt 里补 `no text, no letters, no logos` 不够，**必须逐张放大肉眼扫**；
   → 修法：把"有标签的物件"从画面里删掉（product_5 改成无字空白包装袋 + 去掉护照；product_2 改成纯色无 logo 墙面），
   → **product_2 试了 4 版**：原始版（构图好但角落有假 logo）→ 去 logo 版（构图空）→ 两色版（变成藤编+布衬里，与真品不符）→ 最终版（"fully woven" 措辞 + 居中构图，一次到位）。
   → **建议下次直接用候选文件名生成再比对**，不要覆盖原图（本次靠 `/tmp/xhs_imgs_1103/product_2_backup.jpg` 兜底才没翻车）。
9. **`item.jd.com` / `search.jd.com` 依旧不可用** —— 继续用 `www.jd.com/phb/*.html` 榜单页做 `links.primary`（今天 5 个主推全部如此）。
