## 踩坑记录
1. **`timeout` 命令在 macOS 不存在** — 需改用 Python 超时或 `gtimeout`。

2. **git push 必须走 Clash 代理 7897，prompt 里的绕过命令是错的** ⚠️ 重要
   - prompt 指示「直接 `git -c http.proxy= -c https.proxy= push origin main` 绕过」→ **直连 github.com 20s 超时**。
   - `common.sh` 的 `git_proxy_push()` 同样写死 `proxy=`（绕过代理）→ 在当前网络下必失败。
   - 实测**唯一可用**方式：`http(s).proxy=http://127.0.0.1:7897`
     （`scutil --proxy` 显示系统 HTTP/HTTPS Proxy = 127.0.0.1:7897，进程为 Clash Verge / verge-mihomo）。
   - ⚠️ `HTTPS_PROXY`/`HTTP_PROXY` 环境变量指向 `127.0.0.1:6696`，该端口**已死**（couldn't connect），
     不能依赖环境变量，必须显式指定 7897。
   - ⚠️ `curl -x http://127.0.0.1:7897 https://github.com` 会 SSL_ERROR_SYSCALL 失败，
     但 `git ls-remote` / `git push` 走同一个代理**能成功** — 排查时别被 curl 结果误导。
   - 建议后续修 `common.sh` 的 `git_proxy_push()`，把 `-c http.proxy= -c https.proxy=` 改为读取系统 proxy 端口。

3. **首次 push 遇到远端 unpack 失败**（可重试成功）
   - `remote: error: unable to write file .../objects/.../*.pack: No such file or directory`
     + `remote: fatal: unable to rename temporary '*.pack'` → 远端仓库瞬时故障。
   - 原样重跑一次即成功（`Everything up-to-date`），本地/远程 SHA 一致。
   - 仓库 size-pack 已达 **480.98 MiB**（321 objects），长期增长需关注，必要时清理历史大图。

4. **meta 标签 sed 空格陷阱** — `index.html` 实际格式是 `content="..." />`（斜杠前有空格）。
   prompt 里给的 `sed "s/content=\"[^\"]*\" \/>/.../"` 模式漏掉了 Cache-Control/Pragma/Expires/data-version 共 4 个标签，
   首轮执行静默失败（grep 无匹配 → exit 1）。已改为逐标签精确 sed 并加「残留旧版本号」检查兜底。

5. 环境变量不跨 bash 调用持久化，每个命令都需重新 `source /Users/xiaoan/WorkBuddy/common.sh`。
