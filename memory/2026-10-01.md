### ⚠️ 重要发现: push 不能绕过 proxy

任务 prompt 写的 `git -c http.proxy= -c https.proxy= push origin main`（绕过代理）**本次失败了**:

```
error: RPC failed; curl 28 Failed to connect to github.com port 443 after 75000 ms
send-pack: unexpected disconnect while reading sideband packet
fatal: the remote end hung up unexpectedly
```

排查: `curl --noproxy '*' https://github.com` 直连 **20s 超时**;
而走本地代理 `127.0.0.1:6696` **0.7s 返回 200**。

**本机 GitHub 必须走代理**（`HTTP_PROXY/HTTPS_PROXY=127.0.0.1:6696`, 与 `scutil --proxy` 一致）。
下次直接用:

```bash
cd ${TASK_XHS_DIR}
GIT_SSL_NO_VERIFY=1 git \
  -c http.proxy=http://127.0.0.1:6696 \
  -c https.proxy=http://127.0.0.1:6696 \
  push origin main
```

⚠️ 这条要改回 cron prompt: 现在 prompt 里"直接绕过 proxy"的指引在当前网络环境下是错的, 照做必失败。
