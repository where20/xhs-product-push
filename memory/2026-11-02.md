## 🐛 踩坑与新发现

1. **`jd_fetch.py --json` 参数无效** —— 脚本只实现了文本输出，`--json` 仍打印文本块。
   → **本次绕法**：直接 `import jd_fetch` 调 `parse_phb()` 拿结构化数据，比解析 stdout 稳。
   → 建议后续把 `--json` 修好（属于 `scripts/` 代码，本次未改动以免影响线上）。
2. **jd 主图 URL 会被脚本打印截断** —— 正文输出里是 `.../0083320320`，**真实 URL 还带后缀**（如 `0083320320dc8e12.png`）。
   → 直接拿打印出来的 URL curl 会 **405**；用 `parse_phb()` 返回的原始 `image` 字段拼 `/n1/s450x450_jfs/` 才 200。
   → 昨天日志里「s450x450 要带 Referer」其实不是关键，**关键是 URL 完整**（本次 Referer + UA 都加了也照样 405，URL 修正后一次成功）。
3. **jd 榜单页内容会按关键词轮换** —— 同一个 phb 页两次抓可能返回不同品类：
   - `key_13158b6221d75c64cc64`（男士秋衣秋裤榜）第一次抓出蕉内，第二次抓出棉十三/拾袜记
   - `key_98554007962b1e6ad91f`（木灯具床头灯榜）抓出吸顶灯/落地灯，**不是台灯**
   → **必须逐条 read 真实商品名**，一个品类要多试 2~3 个榜单 URL。
4. **价格会随节点漂移，实时抓 ju 页才准** —— 搜索快照里倍轻松 N6mini「颈椎按摩仪器」显示 **¥298.45**，实时抓 `ju/s1z5vww` 是 **¥507.12**（超 ¥500 价带）。
   → **当场换品**：改用同品牌 N5mini（主图 ¥299，在带内），**没有硬凑一个超价商品**。
5. **主图价与榜单价不一致是常态** —— 松下致儒PRO 主图印 ¥559（超带）、zhuomiwang 榜 ¥549；雷士小夜灯主图 ¥58 / 榜内同系列 2400mAh ¥47.94。
   → 以**主图价（与 SKU 严格对应）**为准，榜单价只写进 `price_note` 做区间参考。
6. **smzdm `ju` 页正则必须整段一起抽** —— 价格排在商品名前面，且规格后缀（含空格/括号）会把商品切断。
   → 用 `([\d.]+元(?:（[^）]*）)?)\s+(.{3,50}?)\s+(京东|天猫精选|...)` 分组抽，且价格要兼容「(需用券)」后缀。
