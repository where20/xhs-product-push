## 🔧 本次踩坑与解决

1. **`timeout` 命令在 macOS 不存在** → `timeout 900 python3 collect.py` 直接 `/bin/bash: timeout: command not found`，后台任务假成功退出。→ 去掉 timeout 重跑
2. **JD 价格 API 全线不可用** → `p.3.cn` 被 DNS 劫持到内网假 IP（DoH 全局查询都是假 IP，不是本机 DNS 问题）；`search.jd.com` 反爬 302 到「京东验证」；`item.jd.com` 200 但返回通用首页。→ 改用 **smzdm 商品页明文价格**（HTML 里直出，无需渲染）
3. **榜单页数据在服务端直出，搜索页在客户端渲染** → 同样「都是 jd.com」，`jd.com/phb/*.html` 可解析出 name/sku/评论数/主图，`list.jd.com` 却是空 SPA。→ 固化判断：只抓 phb 榜单页
4. **榜单页价格是 JS 渲染的**（`<span class="price-rmb" data-skuId="...">` 值为空）→ 价格必须走 smzdm，不要试图从榜单页抠
5. **榜单页会因关键词轮换而变** → `木积盒子排行榜` 页面实际返回的是收纳盒而非乐高积木；`水笔竹子排行榜` 返回的是吴竹水彩笔而非中性笔。→ 用「品牌/品类定位词」筛榜单页，并在写之前**逐条 read 产品名**，不靠网页标题想当然
